# SwapIt — Sustainable Community-Based Item Exchange

## Project Overview

**SwapIt** is a sustainable community-based item exchange prototype designed to encourage responsible consumption and reduce waste by allowing users to exchange unused items within their communities.

The project was developed using **Human-Computer Interaction (HCI)** principles and a **User-Centered Design (UCD)** approach, with a focus on usability, simplicity, trust, accessibility, and community engagement.

## Project Objectives

* Encourage the reuse of unused items.
* Reduce unnecessary waste and overconsumption.
* Provide a simple and user-friendly item exchange experience.
* Support trust and safety between users.
* Encourage sustainable and responsible consumption.
* Improve community participation through digital interaction.

## Key Features

* User registration and profile creation
* Item listing
* Categorized item browsing
* Keyword-based search
* Exchange requests
* In-app messaging
* Notifications
* Ratings and reviews
* Verified profiles
* Favorites
* Rewards and badges
* Request status management

## Design & Methodology

The project followed a **User-Centered Design (UCD)** methodology. The design process included:

1. Understanding the context of use
2. Specifying user requirements
3. Designing and prototyping
4. Evaluating the prototype
5. Refining the design based on usability findings

The project progressed from initial paper prototypes to a high-fidelity interactive prototype developed using **Figma**.

## Usability Evaluation

Several evaluation methods were used to identify usability issues and improve the prototype:

* **Heuristic Evaluation**
* **Discount Usability Testing**
* **Cognitive Walkthrough**
* **Remote Usability Testing**

The evaluation identified issues related to feedback visibility, navigation, trust, error prevention, and interaction flow. These findings led to improvements such as clearer feedback messages, confirmation screens, improved notifications, better navigation, and enhanced trust features.

## 📊 Research Highlights

The study collected **92 survey responses** and conducted semi-structured interviews with **18 participants**.

Key survey findings included:

* **89.1%** agreed that item swapping contributes to sustainability and waste reduction.
* **79.3%** considered item swapping a practical alternative to purchasing new items.
* **71.7%** indicated that they would consider continuing to use item swapping as part of their lifestyle.
* **57.6%** expressed hesitation or uncertainty about exchanging items with strangers.

These findings influenced the inclusion of features such as ratings, verified profiles, secure communication, and clearer exchange-status feedback.
